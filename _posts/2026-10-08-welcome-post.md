I’m excited to share the latest of my many random projects: a website *cataloguing* my many random projects! The goal of this website is to serve as a place where I can go more in depth. A place where I can share more details, pictures, and updates on all the different projects I have. However, if you *still* want more information, please don't hesitate to reach out! You can contact me at: 
{: .box-note}
BLBerkbile@gmail.com

If you'd like to look at any of my projects, feel free to select them from the **Projects** dropdown, or search for them with the search bar. At the moment I've only uploaded a limited selection of projects, so its probably easiest just to use the dropdown selector.

For each of the project logs, I've tried to follow a general format focusing on an initial description of the idea/problem I'm trying to solve followed by the solution I'm using in broad terms. After that I've gone ahead and added sections focusing in greater detail on any key features or challenges I had to overcome. I've also tried to include lots of pictures to keep things interesting!

Many of my projects are either currently ongoing or I have changes/updates/related things I'd like to do with them. As those occur, I'll make more blog posts like this one to keep track of them. Additionally, both the projects and blog posts are tagged, which should help you sort through content of interest.

I’m no web designer, but I had a lot of fun building this site on my own using Github Pages. I didn’t make it without help, the biggest being the template I based the website off of (“Beautiful Jekyll” by Dean Attali). Between that template and the other documentation that Github Pages and markdown provide, it was a pretty smooth process getting this put together. I’ve included all the main resources I used in the **Resources** tab at the top of this site. Feel free to check those out, especially if you want to make your own website!

That's the end of that so I'm proud to say

**Welcome to Bensgineering.org**

(I think I'm the most proud of that name)
